# Render MD
### How to implement into ur code:
use:
```html
<script src="https://cdn.jsdelivr.net/gh/cluster314/Render-MD@main/render-markdown.js"></script>
```
### How to use
in the place where u want to put MD, put `<md>` tags, and put ur md inside.

u can do anything in MD, except footnotes are different:

word[]{thing to put in text}

output:

word^1 (number depends on how many footnotes were there before it) (one is highlighted and when clicked, opens a box that says: thing to put in text)
